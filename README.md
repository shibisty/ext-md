# Media Grabber

Расширение для Chrome и Firefox: показывает все картинки и видео на текущей
странице в виде таблицы, позволяет выбрать нужные и скачать их — одним
кликом, горячей клавишей, поштучно или архивом.

## Возможности

**Поиск медиа**
- `<img>`, CSS `background-image` (в т.ч. через `getComputedStyle`),
  `<video>`/`<source>` (включая `blob:`-ссылки — HLS/DASH-плееры).
- Разбор подключённых `.css`-файлов и `<style>`-блоков — находит фоновые
  картинки, заданные через селекторы (`:hover`, `::before` и т.п.), которые
  не видны через `getComputedStyle` обычных элементов.
- Записи сетевых запросов (`performance.getEntriesByType('resource')`) —
  подхватывает изображения/видео, которые уже загружались страницей, даже
  если сейчас не видны в DOM (лениво подгруженные, замененные и т.п.).
- Все источники объединяются в единый список **без дублей** — сравнение по
  абсолютному URL.

**Таблица и выбор**
- Колонки «Картинка / Размер / Формат», сортировка кликом по заголовку.
- Обычный клик — выбрать/снять одну строку.
- **Shift+клик** — выделить диапазон строк.
- **Ctrl/Cmd+клик** — точечно добавить/убрать конкретную строку из выбора.
- **Протяжка мышью** (зажать и вести по строкам) — быстро выбрать/снять
  сразу много строк.
- Фильтр по типу (Все / Картинки / Видео) и **по размеру** («от … до …» px
  по большей стороне изображения/видео) — элементы с неизвестным размером
  фильтром не скрываются.
- При наведении на строку — на самой странице подсвечивается соответствующий
  элемент **красной внутренней рамкой** (для картинок из CSS-файлов — по
  совпадению фонового изображения, если конкретный DOM-узел не определён
  однозначно).
- Двойной клик по строке или иконка «⤢» — открыть увеличенный просмотр
  (картинка/видео) прямо в попапе.
- Выбор **запоминается по точному URL страницы** — вернувшись на ту же
  страницу, увидите те же галочки, что оставили в прошлый раз.

**Скачивание**
- Кнопка «Скачать выбранное» и **горячая клавиша** (по умолчанию
  `Ctrl+Shift+M`, на Mac `⌘+Shift+M`) — скачивают всё отмеченное одним
  действием, без диалога на каждый файл.
- Три режима сохранения (настраиваются один раз в Настройках):
  1. **Папка загрузок** — файлы уходят в `Downloads/<папка>/<сайт>/…`,
     диалог не показывается вообще.
  2. **Один .zip-архив** — всё выбранное упаковывается в один файл и
     скачивается разом.
  3. **Папка по выбору** — вы указываете папку на диске **один раз**,
     дальше все файлы пишутся прямо туда без повторных запросов (можно
     сменить папку или вернуться к обычному режиму в Настройках в любой
     момент). Доступно только в Chrome/Edge — так работает File System
     Access API браузера.
- Горячая клавиша скачивает всё разом полностью «в фоне», без открытия
  попапа — кроме режима «папка по выбору», для которого браузер обязательно
  требует открытое окно расширения (ограничение самого API выбора папки).

**Боковая панель**
- Иконка «⇱» в попапе открывает тот же интерфейс в боковой панели: в Chrome —
  side panel (Chrome 116+), в Firefox — sidebar. Панель сама пересканирует
  страницу при переключении вкладки и после загрузки новой страницы.

**Настройки** (иконка «⚙» или через `chrome://extensions`)
- Язык интерфейса: системный (по языку браузера) или явно ru/en/uk.
- Тема: системная / светлая / тёмная (быстрый переключатель 🌙/☀ в попапе
  задаёт светлую/тёмную вручную, а «системная» возвращается только здесь;
  в «системной» тема следует за ОС на лету).
- Режим и папка сохранения (см. выше), название подпапки для режима
  «Папка загрузок».
- Просмотр текущей горячей клавиши и кнопка для её смены (открывает
  системную страницу горячих клавиш браузера — сами расширения не могут
  менять их в обход этой страницы).
- Очистка запомненных выборов по страницам (хранятся последние 300 страниц,
  более старые вытесняются автоматически).

## Установка (для разработки)

```bash
npm install
npm run build          # dist/chrome и dist/firefox
```

**Chrome / Chromium / Edge**
1. `chrome://extensions` → включить «Режим разработчика».
2. «Загрузить распакованное расширение» → выбрать папку `dist/chrome`.

**Firefox (115+)**
1. `about:debugging#/runtime/this-firefox` → «Load Temporary Add-on…» →
   выбрать `dist/firefox/manifest.json`.
2. В Firefox до 127 права на сайты (`<all_urls>`) не выдаются при установке —
   разрешите их на `about:addons` → Media Grabber → «Права», иначе
   сторонние CSS-файлы не будут разбираться.
3. Режим «Папка по выбору» в Firefox недоступен (нет File System Access API) —
   используйте «Папку загрузок» или «.zip».

## Разработка

| Команда | Что делает |
|---|---|
| `npm run dev:chrome` / `dev:firefox` | сборка в режиме watch |
| `npm run build` | обе сборки |
| `npm run typecheck` | `tsc --noEmit` |
| `npm test` | unit-тесты (Vitest + jsdom) |
| `npm run test:e2e` | e2e в настоящем Chromium с загруженным расширением (Playwright); первый раз: `npx playwright install chromium` |
| `npm run zip` | сборка + архивы для Chrome Web Store, AMO и архив исходников для AMO в `dist/` |
| `npm run check` | typecheck + тесты + сборка |

Устройство кода, решения и план развития — в [ARCHITECTURE.md](ARCHITECTURE.md).

## Ограничения

- `blob:`-видео в режиме «Папка загрузок» (по умолчанию) скачиваются через
  нативный клик по невидимой ссылке прямо на странице — так браузер сам
  стримит файл на диск, без ограничений по размеру и без зависимости от
  открытого попапа. Платим за это тем, что такие файлы всегда уходят в папку
  загрузок браузера по умолчанию (без вложенной подпапки сайта) — путь для
  `blob:`-видео настроить нельзя, это ограничение самого механизма
  `<a download>`.
- В режимах «.zip» и «папка по выбору» `blob:`-видео передаются наружу кусками
  по несколько МБ (без раздувания в base64 целиком), поэтому большие файлы не
  падают из-за нехватки памяти. Но для .zip итоговый файл в любом случае
  собирается целиком в памяти перед скачиванием — для очень больших наборов
  (например, несколько часовых видео разом) надёжнее режим «Папка загрузок»
  или «Папка по выбору», а не «.zip».
- Режим «Папка по выбору» — единственный режим, которому обязательно нужно
  открытое окно расширения (попап/боковая панель) на всё время скачивания:
  так устроен File System Access API браузера, обойти это нельзя. Режимы
  «Папка загрузок» и «.zip» отправляют всю работу в фоновый процесс
  расширения и переживают закрытие попапа.
- Расширение не обходит DRM и не скачивает то, что браузер и так не смог
  бы загрузить в текущей сессии.
- Режим «Папка по выбору» — только Chrome/Edge.
- Разбор сторонних `.css`-файлов ищет `url(...)` текстовым способом (без
  полноценного парсинга CSS, комментарии вырезаются заранее).
- В режиме «Папка по выбору» файл с уже существующим именем не
  перезаписывается — сохраняется как `имя (2).jpg`.
